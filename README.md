# WeatherDashboard

A SwiftUI weather dashboard application for iOS and macOS.

## Overview

WeatherDashboard is a native Apple platform app built with SwiftUI. It provides a clean, intuitive interface for viewing weather information.

## Requirements

- Xcode 15 or later
- iOS 17+ / macOS 14+
- Swift 5.9+

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Dulneth-Bernard/WeatherDashboard.git
   ```
2. Open `WeatherApp.xcodeproj` in Xcode.
3. Select your target device or simulator.
4. Build and run the project (`⌘R`).

## Project Structure

```
WeatherDashboard/
├── WeatherApp/
│   ├── WeatherAppApp.swift   # App entry point
│   ├── ContentView.swift     # Main content view
│   └── Assets.xcassets       # Image and color assets
└── WeatherApp.xcodeproj      # Xcode project file
```
